# Onur Sports – Web

Canlı futbol maçları web uygulaması.

## Özellikler
- 📱 Responsive: mobil, tablet, masaüstü
- ⌨️ Klavye navigasyonu (ok tuşları + Enter)
- 🖱️ Mouse & dokunmatik ekran desteği
- ⛶ Tam ekran modu
- 🔄 5 dakikada bir otomatik yenileme
- 📦 PWA – "Ana Ekrana Ekle" desteği

## Geliştirme

Direkt tarayıcıda açabilirsiniz:
```
open index.html
```

Ya da yerel sunucu:
```
npx serve .
```

## Yayına Alma

**Vercel (Önerilen):**
1. GitHub'a push edin
2. [vercel.com](https://vercel.com) → Import → Repo seçin
3. Deploy — bitti!

**Netlify:**
1. GitHub'a push edin
2. netlify.com → Add new site → Import from Git
